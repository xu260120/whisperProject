# WhisperWords · 悄悄话背单词

一个**本地优先**的英语背单词应用：白天按记忆曲线正常学习，晚上可选开启「悄悄话」模式，轻声巩固当天学过的词。

> **项目状态：规划阶段，代码尚未开始。** 需求与技术选型已确定，开发从 P0 骨架开始。本文会随开发逐步完善。

---

## 定位

核心是**背单词 App**，不是音频处理工具。「悄悄话」是可选的辅助复习方式，用于睡前巩固，不是主功能。

不夸大睡眠学习的效果：晚上播放的是**当天已经学过的内容**，用来巩固；不承诺"睡觉也能学会新词"。

## 核心功能

- **双队列每日任务**：新背单词与到期复习各自独立，数量默认 10、可调至 100（10 的倍数）。
- **三种题型**：卡片翻面、选择题、拼写题；连续答对达标标记"已掌握"。
- **记忆调度**：采用 FSRS（自研 Dart 实现），保留 SM-2 兜底。
- **悄悄话模式（可选）**：范围可选当日新词 / 当日复习词 / 自选词；先中后英或先英后中、语速、间隔、重复次数、定时、锁屏播放均可配置。
- **词书与词表**：内置四级、六级词书且可扩展；支持导入 PDF / Markdown 词表（一行一词）；释义由内置 ECDICT 词库补全。
- **进度管理**：本地自动保存，支持导出 / 导入 JSON 文件迁移设备；无账号、无服务器。
- **深浅主题**：跟随系统或手动切换。

## 技术方案

| 项 | 选型 |
|---|---|
| 框架 | Flutter + Dart |
| 语音合成 | `flutter_tts`（TTS 与音频导出）|
| 本地数据库 | Drift / Isar（待定其一）|
| 调度算法 | FSRS 自研实现 + SM-2 兜底 |
| 释义词库 | ECDICT（MIT，精简离线）|
| 进度迁移 | JSON 文件导出 / 导入 |
